# PvZ2: Gardendless 合成推理助手

这是一个为 **PvZ2: Gardendless** 的合成推理游戏设计的算法程序，帮你根据每轮反馈推理出十个槽位里的复合植物。它是一个静态网页，计算全部在浏览器里完成，不依赖游戏环境运行。

## 第一次使用

符号约定如下：将游戏中的十种初始植物按固定顺序记作 **1～10**，之后保持这个顺序。配方 `1+10` 表示素材 1 与素材 10，`2+2` 表示两个素材 2。目前版本的程序仅支持十个复合植物的情况。
1. 记录哪些配方能合成；如果已有适用于当前游戏版本的规则文件，也可以点击「导入 JSON」。
2. 前往「对局助手」，选择算法，点击「开始新对局」。
3. 十格建议与游戏槽位从左到右一一对应，照着算法的建议在游戏中填写即可。
4. 填好十格反馈后，点击「提交反馈，计算下一轮」。重复操作，直到十格全部正确。

## 合成表维护

在游戏中并不是任意两种初始植物均可复合，因此玩家需手动维护一张合成规则表。初次打开时，合成表为空，需要你根据实际游戏确认。

- 先选择「可合成」「不可合成」或「未确认」，再点击对应格子。
- 表格上下对称：修改 `1+2` 时，`2+1` 会同步更新，不必填写两次。
- 共 **55 个不同组合**。全部确认，并且至少有 **10 个可合成配方**，才能开局。
- 建议在「游戏版本 / 备注」里记录规则对应的版本，确认后点击「导出规则」留一份备份。

对局期间，合成表会锁定。本局结束后可以修改；每局记录都会保留它开始时使用的规则。如果中途发现合成表填错，请结束本局、修正规则，再重新开始。

## 结果反馈和迭代
玩家得到的反馈以以下代号呈现。

| 代码 | 游戏反馈 | 含义 |
|---|---|---|
| `G` | 完全正确（绿色） | 配方和位置都正确，这个槽位随后锁定。 |
| `B` | 栏位错误（蓝色） | 该配方是本局答案之一，但在其他位置。 |
| `P` | 部分正确（紫色） | 该配方不在本局十个答案中，但与本格答案共享一个素材。 |
| `X` | 完全错误（红色） | 以上条件均不成立。 |

例如，`GBPPXXXXXX` 表示第一格绿色、第二格蓝色、第三和第四格紫色、其余六格红色。

**照抄游戏反馈即可。** 蓝色优先于素材匹配：游戏显示蓝色时，即使你认为素材也有重合，仍应填 `B`。

如果游戏里实际填写的配方与建议不同，先勾选「修改实际填写」，把它改成实际尝试的配方，再提交反馈；此外，同一轮可以在不同槽位填写相同配方；看到重复建议是正常的。

## 两种算法怎么选

| 算法 | 适合什么情况 |
|---|---|
| **联合抽样搜索** | 综合考虑十格之间的关系，计算量较大。 |
| **轻量探针** | 希望更快得到建议，或者设备运行联合方法较慢时使用。 |

两种方法都是启发式策略，算法在本局内固定。助手有时会建议一个已经确定不是答案的配方，这是有意为之的。

## 填错时该如何处理

如果是提交时提示矛盾，那么这轮输入会保留供你修改，不会加入正式历史。先检查实际填写、反馈顺序、合成表是否准确；如果发现是历史轮次填错，点击「撤回上一轮」，原来的配方与反馈会回到输入区。可以逐轮撤回到出错的位置，修正后重新提交；之后的推理需要重新进行。

## 保存、备份与换设备

助手自动保存合成表、当前对局和未提交输入。关闭网页前，请确认侧边栏显示 **「已保存到此浏览器」**。

这里的保存是浏览器本地保存，没有账号或云端同步。换浏览器、换设备、换网址或清除站点数据后，原存档可能无法继续使用，请提前备份。

- **导出规则：** 保存合成表，方便下次使用或分享给使用同一游戏版本、同一素材编号的玩家。
- **导出对局：** 保存本局所用规则、尝试记录和当前输入，便于备份和恢复。
- **导入 JSON：** 选择之前导出的文件。导入会替换相应的规则或对局，请先备份已有记录；正在进行的对局需要先结束。

如果提示保存失败，先使用页面提供的「重试保存」或「导出当前输入」，不要急着刷新或关闭。尽量只用一个标签页操作；如果提示另一个标签页更新了存档，先导出当前输入，再点击「重新读取存档」核对。

## 使用范围

本助手适用于以下规则：十种初始素材、十个互不相同的答案；每个答案由两个素材合成，允许相同素材，合成顺序无关；每种合法配方对应不同的复合植物；反馈按上表的顺序判定。

如果游戏版本改变了这些机制，仅修改合成表可能不足以适配。

网页加载完成后，推理和保存不需要网络。但目前不保证断网后还能重新打开网页，重要记录请另存 JSON 文件。
